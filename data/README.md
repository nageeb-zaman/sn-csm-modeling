# Data

No simulation output or observational data are stored in this repository.

- **Model outputs** (MESA, STELLA, SuperLite) are large and are not included.
  The scripts in `analysis/` take paths to your own run folders.
- **Observed spectra and light curves** can be obtained from public archives
  such as WISeREP (https://www.wiserep.org) and the Open Supernova Catalog.
  Please cite the original papers for each object you use.
